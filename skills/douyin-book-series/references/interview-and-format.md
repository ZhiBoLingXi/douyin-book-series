# 编导取舍

先看已上传的书、当前对话和同项目已确认的目标。用户只给书时，围绕潜在读者能从这本书得到什么来写；如有关键假设，在合集说明里用一句话记录。无需用户决定时长、集数、画面风格或 SOP。默认全书改编；商业目标影响表达与结尾承接，不替代全书覆盖。

| 情形 | 会改变成稿的决定 |
|---|---|
| 希望引发购买兴趣 | 当集交代清楚自己的答案，留下一个只有进一步阅读才值得展开的问题。用书里具体的章节、案例或人物分歧给出试读理由。封面、简介和结尾共同服务这个理由。 |
| 希望观众追更 | 当集兑现开头的承诺，再给出下一集独有的问题。独立刷到中间一集的观众也要能辨认人物、时间和处境。 |
| 商业史、传记 | 按人物在当时掌握的信息讲选择与代价；分别标清作者观察、当事人自述、编导判断。拟制图表和场景标明示意。 |
| 小说 | 从可见动作与局部冲突切入。默认全书改编，覆盖核心谜底和结局；用户明确要求不剧透或只做试片时，遵守限制并说明未覆盖范围。购书目标可用人物细节、叙述层次或未展开的支线提供阅读理由。 |
| 科普、知识书 | 从可演示的问题进入，用图解、例子或反例解释原理并注明适用条件。为视频新编的例子标明为示意。 |

真人是否出镜、是否使用生成素材等选择以现有资源为准。素材来源不明时，可以设计一张能表达同一信息的原创图卡。若对标材料可读，记录具体视频的开场、信息揭示、声音与收束；只迁移适合本书的做法，记录观察范围。

面向以听为主的栏目，可让一句开场白同时承担定位和入题，念完直接接正文。按当集内容选起点：传记讲人物眼下的处境，小说讲眼前发生的变故，科普讲可观察的现象，实用书讲听众手上要解决的任务。混合文体跟着本集走。需要统一辨识时可保留书名或已确认的栏目短句。对通勤与睡前等收听偏好分别判断；口播是否离得开画面可核稿，语速、声响和最佳时长的实际效果需要相应场景的试听。
